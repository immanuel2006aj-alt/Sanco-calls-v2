# Sanco Video Calls

Private, encrypted, 1‑to‑1 video calling in your browser. No account needed.

## Features
- Secure random Call IDs
- Camera, microphone, screen sharing, fullscreen, PIP
- **Ghost Mode** – become invisible (live ghost avatar + mute)
- Encryption badge visible (DTLS/SRTP)
- Network recovery, adaptive quality
- Responsive, accessible, privacy-first
- Deployable on GitHub Pages

## Deployment
1. Clone this repo.
2. Deploy to GitHub Pages.
3. Or run `node build/lock.js` to minify and deploy.
